# Expense Tracker System

A full-stack Expense Tracker application built using multiple technologies.

## Technologies Used

### Frontend

* React.js
* Vite
* JavaScript
* CSS

### Backend Implementations

* Spring Boot
* FastAPI
* Node.js

### Database

* PostgreSQL

## Features

* User Registration and Login
* JWT Authentication
* Expense Management
* Add Expenses
* View Expenses
* Dashboard
* Reports
* Profile Management
* Admin Panel

## Project Structure

Expense_tracker

* frontend-final → React Frontend
* expense-tracker-api → Spring Boot Backend
* fastapi-final → FastAPI Backend
* expense-tacker-nodejs → Node.js Backend
